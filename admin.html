Google Gemini API Key

API Key miễn phí ~1.500 tin nhắn/ngày. Anh lấy tại: aistudio.google.com/app/apikey

Đang kiểm tra trạng thái Máy chủ...

Google OAuth Client ID

Cần có Client ID để tính năng đăng nhập Google hoạt động.
Lấy tại: console.cloud.google.com → APIs & Services → Credentials → Create OAuth 2.0 Client ID

🔗 Nhúng Widget Vào WordPress

📋 Bước 1 — Copy đoạn code này

📌 Bước 2 — Dán vào WordPress

1. Vào WordPress Admin → Appearance → Theme Editor
2. Hoặc dùng plugin "Insert Headers and Footers" (khuyến nghị)
3. Dán code vào phần Footer Scripts
4. Nhấn Save → Widget sẽ xuất hiện góc phải website ạ!
